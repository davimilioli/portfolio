A Unycall foi um projeto desenvolvido durante o período de estudos em Back-End, com o objetivo de simular uma empresa do setor de telecomunicações. O sistema foi projetado para oferecer uma ampla gama de serviços de comunicação, garantindo conectividade eficiente para indivíduos e empresas. Durante o desenvolvimento, utilizei APIs de CEP para cadastro de usuário.

## Destaques

- Adicionar novo usuário
- Excluir usuário
- Editar usuário
- Autenticação de usuário
- Autenticação 2FA
- Sistema de assinatura mensal
- Sistema de pagamento fictício
