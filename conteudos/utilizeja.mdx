O Utilize Já é um app utilitário criado para simplificar tarefas cotidianas. Desenvolvido como projeto de estudo em desenvolvimento mobile, o aplicativo conta com autenticação com Firebase, sistema de bloco de notas e uma ferramenta integrada para conversão de imagens em PDF.

## Destaques

- Autenticação com Firebase
- Conversor de imagem para PDF
- Consulta de CEP
- Conversor de Unidades (medidas de peso, volume, distancia, etc.)
- Bloco de Notas
- Lista de Tarefas
